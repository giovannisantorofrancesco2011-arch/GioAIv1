# Acchiappa le stelle

Gioco 2D in Python con Pygame: il giocatore muove un cestino con le frecce e prende le stelle.

## Comandi
- installa: `python -m pip install -r requirements.txt`
- avvio: `python main.py`

## Convenzioni
- tutto il gioco è in main.py: costanti in alto (dimensioni, colori, velocità), poi il ciclo principale
- il ciclo fa sempre: eventi → aggiornamento → disegno → clock.tick(FPS)
- commenti e testi in italiano
